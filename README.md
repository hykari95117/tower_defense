# season_tower_defense
- 4계절이 main theme인 게임
- 계절에 따라 공격, 스킬, 몬스터 등이 영향을 받는다.
- 상단에 시간의 흐름을 나타내는 타임 게이지 있음

## main concept
- 게임은 최대한 간단한게, 3살짜리도 10초만에 이해 가능한 게임
- 탑은 정중앙에 위치, 탑이 움직이거나 개수가 늘어나는 컨셉의 게임이 아니다.
- 신화 무기, 전설 무기 그런건 없음
- 과금 요소 절대 없음

## attack concept
- 레벨 올라가면 탑 확장 or 공격력 강화
- 처음부터 강한 공격 or 화려한 공격으로 시작, 딱총 같은 심심한 공격은 없다.
- 탑은 못 움직이는 대신 캐릭터 소환(스킬)
  - 로봇이 나와서 하늘에서 미사일 공격(범위 공격)
  - UFO가 나와서 하늘에서 광선 공격(범위 공격)

## ai
- 일정 수준의 level OR wave부터 무기 or 스킬을 ai로 생성할 수 있다.
- 무기 or 스킬은 유저가 입력한 내용을 바탕으로 실시간 생성
  - ex)
  - request
    - 하늘을 날아다니는 불의 용
  - response
    - 이미지(규격화 된 사이즈)
    - 스킬 혹은 공격명(글자수 제한?)
    - 스킬 혹은 공격에 대한 description
    - 대미지(현재 레벨, 웨이브 등에 맞춰서)
